# 📬 Multi Messenger

اپ دسکتاپ **رایگان و متن‌باز** برای ویندوز که تلگرام، دیسکورد، توییتر/X، فیسبوک، اینستاگرام، تیک‌تاک، یوتیوب، جیمیل، یاهومیل و Outlook رو در یک پنجره با سایدبار سمت چپ جمع می‌کنه — شبیه Rambox ولی کاملاً رایگان.

## ✨ ویژگی‌ها

- 🔀 سوییچ سریع بین اپ‌ها از سایدبار سمت چپ
- ➕ افزودن اکانت جدید در هر لحظه با یک کلیک (بدون نیاز به ویرایش فایل یا نصب دوباره)
- 🔒 هر اکانت **session/کوکی کاملاً مجزا** داره — چند اکانت از یک اپ رو همزمان و بدون تداخل لاگین باز نگه دار
- 💾 **بازیابی خودکار آخرین صفحه**: با باز کردن اپ، دقیقاً همون‌جایی که بودی (مثلاً همون کانال تلگرام) باز میشه
- 🗑️ راست‌کلیک روی هر آیکون → حذف اون اکانت
- 100% رایگان، بدون تبلیغات، بدون محدودیت

## 📥 نصب (برای کاربران عادی)

اگه فقط می‌خوای از برنامه استفاده کنی و کدنویس نیستی:

1. برو به بخش **[Releases](../../releases)** همین ریپازیتوری
2. جدیدترین نسخه رو باز کن و فایل `Multi.Messenger.Setup.x.x.x.exe` رو دانلود کن
3. فایل دانلودشده رو اجرا کن و نصبش کن
4. از استارت‌منو یا دسکتاپ بازش کن

> ویندوز ممکنه در اولین اجرا هشدار "Windows protected your PC" نشون بده (چون این اپ امضای دیجیتال پولی نداره). روی **More info → Run anyway** کلیک کن.

## 🛠️ ساخت از کد منبع (برای دولوپرها)

نیاز به [Node.js](https://nodejs.org) (نسخه ۱۸ به بالا) و [Git](https://git-scm.com) داری.

```bash
git clone https://github.com/YOUR-USERNAME/multi-messenger.git
cd multi-messenger
npm install
npm start
```

### ساخت فایل نصبی exe

```bash
npm install
npm run build
```

خروجی داخل پوشه‌ی `dist/` قرار می‌گیره. (اگه روی ویندوز با خطای symbolic link مواجه شدی، PowerShell رو با «Run as administrator» باز کن، یا این دستور رو قبلش بزن: `$env:CSC_IDENTITY_AUTO_DISCOVERY="false"`)

## ➕ افزودن اکانت جدید (داخل خود برنامه)

1. روی دکمه‌ی **+** پایین سایدبار کلیک کن
2. اپ مورد نظر رو انتخاب کن
3. یه اسم دلخواه بذار (اختیاری)
4. «افزودن» بزن و لاگین کن

## 🧩 افزودن یک اپ جدید به لیست انتخاب‌ها

فایل [`catalog.json`](./catalog.json) رو باز کن و یک آیتم اضافه کن:

```json
{ "appId": "whatsapp", "name": "WhatsApp", "url": "https://web.whatsapp.com/", "icon": "💬", "color": "#25D366" }
```

سپس دوباره `npm run build` بزن.
